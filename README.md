```
termux-setup-storage && apt update && apt upgrade -y && pkg update -y && pkg upgrade -y && pkg install git -y && git clone https://github.com/XThrlen/UNPACK-REPACK.git && cd UNPACK-REPACK && chmod +x install.sh && bash install.sh && rm -rf install.sh
```
[>] Done, next time just type **SRCHUB** to execute the tool.
